# How aisitey Works

aisitey uses seven context files to give AI agents complete project knowledge.

## The Seven Files

1. **Project Overview** - What you're building
2. **Architecture** - How it's built
3. **UI Context** - How it looks
4. **Code Standards** - How code is written
5. **AI Workflow Rules** - How AI works
6. **Memory** - What was decided
7. **Progress Tracker** - Where you are

## Benefits

- **Speed**: No re-explaining
- **Consistency**: Same context every time
- **Control**: You define the boundaries
- **Memory**: Nothing gets lost
- **Flexibility**: Any AI agent can work
